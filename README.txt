TUSDEKUL ISLAM — PROFESSIONAL PORTFOLIO WEBSITE
================================================

PREVIEW ON YOUR PC
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Brave.

PUBLISH / UPDATE ON GITHUB PAGES
1. Open your repository:
   https://github.com/tusdekulislam444-beep/tusdekul-islam-portfolio
2. Click Add file > Upload files.
3. Upload the new index.html from this folder (and this README if you want).
4. Click Commit changes. If GitHub asks whether to replace index.html, confirm the replacement.
5. Wait a few minutes, then open:
   https://tusdekulislam444-beep.github.io/tusdekul-islam-portfolio/

BEFORE SHARING WITH CLIENTS
- The portfolio project cards are sample concepts/placeholders. Replace them with your own completed designs.
- Add your real Behance URL when you have one.
- The page uses a TI monogram instead of a personal photo because no photo was supplied.
- Verify the WhatsApp number/link before sharing. It is set to +8801977954092 based on the number supplied in chat.
- You can edit index.html with Notepad or Visual Studio Code. Keep a backup before editing.
